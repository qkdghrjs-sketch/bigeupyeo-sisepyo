# 우리 동네 비급여 시세표

원장님이 병원 이름 하나만 넣으면, 같은 지역·같은 진료과 안에서 우리 병원 비급여 가격이 어디쯤인지와
빠뜨린 신고 항목을 A4 3장으로 뽑아주는 도구입니다. 로그인 없음, 서버 없음, 정적 파일만으로 동작합니다.

- 데이터: 건강보험심사평가원 비급여 진료비용 공개자료 (2026년 9월 3일 공개분 / 2026년 3월 진료분 기준)
- 범위: **전국 256개 시군구 · 72,236개 기관 · 1,138,063건 · 728개 항목**
- 확인일: 2026-09-23

---

## 1. 결과물 3장

| 장 | 제목 | 내용 |
|---|---|---|
| ① | 우리 병원 가격 위치표 | 신고 항목별 우리 가격 / 비교군 최저·중앙·최고 / 하위 몇 % / 신호등 판정(저렴·보통·비쌈) |
| ② | 옆 병원은 신고했는데 우리는 없는 항목 | 같은 지역·같은 진료과 30% 이상이 신고했는데 우리 공개자료에 없는 항목 + 동네 가격대 |
| ③ | 병원별 주요 항목 가격표 | 같은 지역·같은 진료과 최대 38곳 × 주요 8항목 가격 매트릭스, 우리 병원 하이라이트 |

②는 "하고 있는데 신고를 빠뜨린 것"을 찾아내는 장입니다. 변경보고 10일 규정과 과태료 200만원 안내를 같은 장에 붙여 뒀습니다.

## 2. 비교 기준

- **같은 시군구 + 같은 진료과 + 같은 종별**(의원은 의원끼리)
- 비교 기관이 3곳 미만인 항목은 ①에서 제외
- ③은 제증명수수료를 빼고 진료·검사·접종 항목만 (원장님이 돈으로 체감하는 항목 위주)

## 3. 진료과는 어떻게 붙였나 (중요)

심평원 공개자료에는 **진료과 필드가 없습니다.** 공공데이터포털·심평원 병원찾기 API도 확인했지만
외부에는 *암호화된 요양기호*만 제공해서 8자리 요양기호와 조인이 불가능합니다. 그래서 2단계로 추정합니다.

1. **기관명 매칭** — "○○내과의원" → 내과 (의원 35,306곳 중 75.6% 커버)
2. **신고 항목 프로파일 보정** — 1단계에서 못 잡은 곳 중
   - 라식·라섹·시기능검사 있으면 → 안과
   - 도수치료·체외충격파 있으면 → 정형외과
   - 진정내시경관리료·갑상선초음파 있으면 → 내과
   - 모발이식 있으면 → 피부과

결과: 의원 미분류 24.4% → **17.6%**. 나머지는 '기타'로 묶입니다(주로 미용·비만 계열).
미분류 기관을 조회하면 '기타'끼리 비교되므로, ① 표의 비교 기관수를 함께 보고 판단하세요.

## 4. 파일 구조

```
bigeupyeo-sisepyo/
├── index.html          도구 본체 (이 파일 하나가 전부)
├── items.json          항목 사전 728개 [코드, 명칭, 대분류]
├── sggu.json           시군구 목록 + 기관수/행수
├── 311901.json         시군구별 데이터 (예: 고양시 덕양구 588곳 / 9,414건)
├── 110001.json         (예: 서울 강남구 2,625곳 / 32,366건)
├── ...                 총 256개, 29.1MB
├── refresh.mjs         데이터 갱신 스크립트 (node refresh.mjs)
├── 샘플_출력물.pdf
└── README.md
```

시군구 데이터 파일명은 **심평원 시군구 코드**입니다(행안부 코드 아님). 폴더 없이 루트에 둔 것은 GitHub 웹 업로드가 폴더 구조를 보존하지 않기 때문입니다.

데이터는 **시군구를 고를 때만** 해당 파일 하나를 받습니다. 첫 화면은 60KB면 뜹니다.

## 5. 배포

Vercel 정적 배포 그대로 됩니다. 빌드 설정 없음.

```bash
cd bigeupyeo-sisepyo
vercel --prod
```

bangcm.vercel.app 에 붙일 경우 "비급여" 카테고리에 링크 하나만 추가하면 됩니다.

## 6. 데이터 갱신

심평원 비급여 공개자료는 **매년 8월 마지막 주~9월 초**에 새로 공개됩니다. 공개 직후 1회만 돌리면 됩니다.

```bash
node refresh.mjs        # 약 10~12분, d/ + items.json + sggu.json 덮어쓰기
```

갱신 후 `index.html` 안의 `공개자료 기준일 2026-09-03` 문구를 새 공개일로 바꿔 주세요.

## 8. 데이터의 한계

- **미제출 기관은 이 데이터에 아예 없습니다.** 병원 이름을 넣었는데 목록에 없으면 미제출(또는 이름 표기 차이)일 수 있습니다.
  (검증 완료: 심평원 기관검색 응답의 `prsStatTpCd`가 비어 있는 기관은 가격공개자료가 0건입니다.)
- ③의 '미신고'는 "그 병원이 그 항목을 공개자료에 올리지 않았다"는 뜻이지, 진료를 안 한다는 뜻은 아닙니다.
- 가격은 공개자료의 **최저금액(minPrc)** 기준입니다. 최저≠최고인 항목은 ①에서 `~최고가`를 함께 표시합니다.
- 2026년부터 영양주사(11개)·예방접종(4개)·로봇보조수술(11개) 코드가 세분화됐습니다. 작년 코드와 직접 비교하면 어긋납니다.

## 9. 기술 메모 (심평원 내부 조회)

- 엔드포인트: `POST https://www.hira.or.kr/npay/rb/selectNpayDamtPubList.do`
- CSRF: 아무 문자열이나 쿠키 `CSRF_TOKEN`과 파라미터 `_csrf`에 **똑같이** 넣으면 통과 (double-submit)
- 바디 형식: `@d1#필드명=값` + `@d#=@d1#`, `@d1#=dmParam`, `@d1#tp=dm`
- **시군구 코드는 행안부 코드(41281)가 아니라 심평원 코드(311901)** 를 파라미터에 씁니다
- 기관 종별 `clCd`: 01=상급종합, 11=종합병원, 21=병원, 28=요양병원, 29=정신병원, 31=의원, 41=치과병원, 51=치과의원, 92=한방병원, 93=한의원
- 공공데이터포털 "심평원_비급여진료비정보조회서비스" API는 병원급 이상만 제공하므로 의원급에는 쓸 수 없습니다
